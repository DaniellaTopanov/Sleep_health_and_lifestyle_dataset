# Sleep Health Data Regression Analysis

## Overview
This project was developed as part of a statistical modeling course at Ben-Gurion University.
The goal was to analyze sleep health metrics, build linear regression models, and manually derive OLS estimators to verify software outputs.

## Tools & Technologies
- **Language:** R
- **Packages:** `dplyr`

## Key Analysis Steps
- Built simple and multiple linear regression models.
- Performed hypothesis testing (t-test, joint Wald test).
- Conducted model diagnostics and analyzed interaction effects.
